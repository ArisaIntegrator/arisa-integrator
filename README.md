# Arisa Integrator

Arisa Integrator to rozwijany system do integracji sprzedaży marketplace,
obsługi zamówień, magazynu, kompletacji i wysyłek.

## Aktualny etap

Wersja developerska 0.1.0.

Pierwszy etap obejmuje:
- integrację z Allegro Sandbox,
- pobieranie zamówień,
- obsługę kompletacji,
- tworzenie przesyłek i etykiet.

## Status

Projekt w fazie rozwoju.
